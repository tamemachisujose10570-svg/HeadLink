# 1.2.0 最短使用与实测

1. 用原Sideloadly账户/设置覆盖安装新版，不卸载，不改bundle ID。将Pocket机身竖直固定，云台周围留足活动空间；机身选择Follow、关闭ActiveTrack和智能云台。设置里的安装方式保持“机身竖直固定”。
2. 正常连接耳机和Pocket，连接成功自动进入拍摄页。无需填写固件或重复首次实验，等真实姿态和模式参数就绪。
3. 头看向准备作为正前方的方向，让镜头对准对应基准；点“校准”→“开始校准”，保持稳定直到成功，再点“开始／恢复跟随”。校准不机械回中，不自动运动。
4. 正式跟随时分别左右转约30°、抬头约30°，每处保持2秒并回到基准，再做左右+上下组合和侧歪头。用外部方向标记观察镜头真实朝向，不只看目标数字。拍摄页展开“精度与诊断”，对照头部角度、镜头相对校准方向和回报差；数据回报不能代替外部量角精度。
5. 连续运行至少5分钟，测试暂停/继续、原地重新对齐、录像开始/停止和视频。超限应明确提示且不缩放，回到可达范围应恢复原对应关系；任何连接恢复都不自动跟随。故障时立即导出：设置→本地诊断→生成脱敏诊断文件→分享JSON，不反复校准覆盖现场。

若左侧在校准时已接近协议边界，左转30°会限位：这是剩余行程不足，应明确暂停后选择有余量的构图重新对齐，不自动偷偷回中。先确认约30°方向/保持/返回，不要求另做“扩大范围”实验阶段，也不要求扫到物理止挡。

本版不用于随身体移动或倾斜固定的安装。移动补偿未验证，未测量零延迟、零漂移或完整光学精度。反馈请包括：一次校准能否直接开始、各30°方向/保持/回基准与复合转头、5分钟录像/图传情况及诊断JSON。
