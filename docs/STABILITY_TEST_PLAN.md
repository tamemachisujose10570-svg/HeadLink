# 最短真机验证：连续至少5分钟

无需重做权限授权或四向5°实验。用首次相同Sideloadly账户/设置覆盖安装，保持原bundle ID；Pocket机身固定，先用已有局部范围内约±2°～3°测试。

1. 连接后打开“真实数据与跟随准备”，核对实际固件/现场条件并使用已保存配置。进入拍摄页，可打开已有“拍摄页保持常亮”避免5分钟内锁屏干扰。
2. 只完成一次校准，再点开始。应进入跟随：头部左右/上下运动产生新的目标和网络写入，镜头有实际响应。保持姿势时保持目标，回基准时回目标。普通数据更新不能要求再次校准。
3. 连续运行至少5分钟；期间至少一次暂停并继续原关系、一次真实开始录像与停止录像。确认相机本体REC/录像停止与App真实回报一致，同时观察图传、按钮是否闪烁，不能只看发送提示。
4. 若画面暂停，观察“相机控制有回报”是否仍在，录像是否仍响应，图传是否显示恢复动作并真正出现新画面。恢复后跟随应仍暂停，不可自行运动。只有升级到共享UDP重建/真实参考失效才需重新校准，界面必须给出对应原因。
5. 点击开始若再次被拒绝，或出现视频冻结，请立即导出，不要反复重校准冲掉触发现场：右上角“设置”→“本地诊断”→“生成脱敏诊断文件”→“分享JSON”。本轮请确认导出context里的App版本/构建号是新版。

反馈最少包括：连续运行分钟数；一次校准后能否开始/镜头是否动作；录像是否响应；画面暂停/恢复情况；诊断JSON。若5分钟未触发视频故障，只能确认该轮连续运行，不能据此宣布自动恢复已经真机通过。
