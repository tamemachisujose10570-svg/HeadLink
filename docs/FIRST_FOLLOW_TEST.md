# 0.2.0 固定基座首次联动测试

首版阻塞已定位：VerifiedProfiles.json=[]；AppModel 的 profile 匹配同时要求真实型号和 firmware 精确相等，故 canStart 永远为假，TrackingController.start 也会拒绝。此前角度命令链路存在，但没有被这个安装版本调用。首版头部角度仅在完成跟随校准后显示，不能排查首次姿态。此次没有改变配对、Wi-Fi手动加入或预览绑定实现。

## 新版正常验证流程

1. 用同一个Apple签名账户和bundle ID覆盖更新（org.headlink.personal），连接耳机与相机。进入“真实数据检查／首次5°实验”。
2. 看“观察yaw/pitch”、回调Hz与数据时效。左右转头、抬头低头各至少3°。观察零点与相机校准独立，不发任何运动命令；roll不作为yaw/pitch。200ms无新样本灰显不可用；参考跳变要重设观察零点。
3. 看真实识别型号、广播型号编号、固件、镜头yaw/pitch、native pitch、姿态帧长度/有效数、当前模式。如果没有固件回包，可手动输入机身或Mimo核对的完整版本，并勾选人工核对；导出会明确区分相机回报与人工确认。未知型号不能按Pocket4放行。
4. 在机身屏幕顶部下滑，选择Follow/跟随模式，关闭ActiveTrack和智能云台；固定机身，检查被测方向无遮挡。App只读取云台模式/锁定参数，不自动改变模式、速度或重置机械方向。相机明确报告不兼容模式时，不允许用人工确认绕过。
5. 勾选机型/固件、固定支架、跟随模式三项确认，点“准备本次实验”。此时不运动。
6. 点“向右测试到+5°”，在确认弹层再次明确开始。轨迹约2秒、单轴5°，读回姿态到位并稳定后尝试发送停止，再观察至少0.8秒。你确认实际方向、约定角度与停止保持后，才记录端点。
7. 明确点击“沿已测路径返回实验起点”，同样观察并确认。然后分别向左、向上、向下测试，每次都返回并确认。立即停止入口始终可用。反向、横向异常、控制间隔>200ms、相机姿态>300ms、超时、目标队列拒绝会终止；不会在失败后自动返回或自动重试。
8. 四个方向及返回都通过后，点“启用本次实验跟随，返回拍摄页校准”。初次局部包络通常是相对于实验起点的yaw/pitch各±5°，不是机械全行程。
9. 看向希望的正前方，让镜头朝向相同方向，保持静止校准，然后明确点击开始。测试小于已测范围的左右/上下角度，保持、回基准与暂停；恢复可继续原关系或保留构图重新对齐。
10. 要扩大范围，回实验页逐侧增加5°，保留上一轮已测路径，运动时间会随距离增加以保持缓慢。每次都须到位、停稳、物理确认和返回确认；最多本基线左右45°、上下30°且不能超过上游命令候选范围。任何一侧不可达就不要继续扩大，点停止并导出诊断。

## 范围和角度语义

- 复用固定OpenCine commit的gimbalTimedTarget（0x04/0x14），绝对目标，i16 little-endian，角度0.1°，roll ignored。网络角度目标duration=0.1s，实际测试轨迹由有界最新目标流缓慢推进。
- yaw/pitch反馈来自真实50字节0x04/0x05。yaw @4、native pitch @0、显示pitch为@20取负，0.1°；原生命令pitch=起点native pitch−显示pitch增量。
- 上游软件候选范围yaw -48…225°、显示pitch -44…70°仅用于编码/路径拒绝，不能称本机机械范围。首次实验资格不依赖空的正式profile表。
- 本次实验profile只由已确认的端点、返回、停止保持记录建立，包含确切型号、固件与来源；仅本次连接使用，不保存为正式兼容认证。改变模式/身份、断连或离开前台即撤销。
- 在包络内yaw/pitch数学增益严格1.00。超出包络保存未裁剪原始目标、限制命令并提示限位，绝不把30°缩成5°再称1∶1。
- 单轴局部结果不证明整个矩形机械范围或复合运动精度。开始和恢复有速率/加速度限制；稳定目标与最新镜头回报持续相差较大时暂停。回报未时间对齐，不能据此宣布绝对角度精度。
- 停止是notify命令，没有设备停止ACK。“已尝试停止”与随后“回报保持”分开；丢网时不保证命令送达。返回动作永远需要再点击。

## 反馈需要的最少信息

在实验页“生成本次诊断”，用系统分享导出JSON。schema2包含iOS版本、型号/固件及来源、模式、姿态帧长度与计数、头部和相机角度、数据时效/频率、提交目标、实际网络写入数、最近原生命令及拒绝原因、实验回执与阻塞原因；无相机密码、完整设备标识和视频。

请反馈：是否能看到转头时yaw/pitch持续变化；四个小角度是否按预期；若失败，给失败文字与JSON。若设备信息页没有固件项，不猜值，请提供实际看到的菜单名称或页图（隐藏序列号），再核实入口。

模式入口与Follow行为依据[DJI Pocket4官方用户手册，第28–29页](https://terra-1-g.djicdn.com/6189933d30024fc1b331bffe4fe41837/osmo-pocket-4/UM/DJI_Osmo_Pocket_4_um_v1.2_en.pdf)。本次不要求更新固件，以免改变已能连接/图传的基线。
