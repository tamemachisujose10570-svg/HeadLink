# 未验证项与下一次推进顺序

目前可以审查与重建的源码已准备好，不能称完整 App 已稳定交付。按下列顺序继续，不重新选择平台或映射倍率。

1. **云端原生编译**：取得用户指定私有仓库、源码/工作流提交权限，核实免费 Actions 额度和禁止超额。先运行 smoke，随后核心测试和完整 iOS device build；修复真实编译/链接错误。生成 IPA 后才更新“iOS 编译成功”状态。
2. **免费安装链路**：Sideloadly 本地签名，验证没有 Hotspot entitlement 时能启动、配对、手动切 Wi-Fi、接收视频。未经实际安装不能宣布免费签名兼容。
3. **相机信息**：实物型号/固件及 iOS 待用户确认。当前 firmware decoder 仅在收到真实 GetVersion 报告时填值，固定上游没有可找到的专用 GetVersion 请求 builder；如果设备不主动报告，先从合法资料/实际抓取核实请求格式，再补查询。不得猜命令或填假的固件值。
4. **控制坐标与范围**：固定基座测方向、显示/native pitch 关系、当前云台模式与局部可达范围。固件与范围有证据后增加精确 profile（当前空），再开放小角度跟随测试。还要测停止与断网行为、实际码流/控制吞吐。
5. **可用性与呈现**：在真实 iPhone 上检查横竖屏、Dynamic Type、VoiceOver、相机预览+录像+跟随组合负载。未运行 iOS 视觉/交互测试，Swift 语法解析不能替代。
6. **硬件验收**：完成 HARDWARE_TESTS 的误差、漂移、丢包、权限、后台、重复更新/刷新测试，记录原始数据和 build SHA。

明确边界：移动基座、锁屏/后台持续跟随未实现；不读取不公开的耳机电量/佩戴状态；目前没有相机端采样时间对齐、可信的端到端延迟和角度误差显示；没有直接识别相机实体摇杆人工接管的信号。App 不提供手动摇杆操作，不会与自身第二个控制器争夺输出。

当前预览接入包括真实原生链路与 stale 标记；完整上游 picture-recovery 策略没有移植。首次硬件测试若遇到冻结，先保留证据、手动断开重连，再按固定上游的可重现实验增加恢复，不无条件循环 enable。
